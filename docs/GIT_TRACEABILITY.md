## 贡献记录模板

| 日期 | 作者 | Commit SHA | 变更 | 验证 | Issue/PR |
|---|---|---|---|---|---|
| YYYY-MM-DD | 待填写 | 待填写 | Schema/样例/实现 | `python scripts/validate.py` | 待填写 |

## 规则

- 每个功能变更使用清晰的 commit message。
- Schema 变更必须同步更新样例和校验结果。
- 真实实验必须记录输入提交、配置、工具版本和输出提交。
- 不使用虚构的 commit SHA、作者和验证结果。
